# How it works

The mechanisms behind E-Trace, and what keeps each of them honest.

* [Escrow](escrow.md): one escrow per item, with the rules written in the contract.
* [AI auto-settlement](ai-settlement.md): fixed rules first, then an AI that reads the tracking.
* [On-Time Guarantee](on-time-guarantee.md): parametric shipping insurance.
* [Disaster Radar](disaster-radar.md): real disasters, AI assessment, on-chain donations.
* [Transparency Explorer](explorer.md): public numbers you can check yourself.
* [Wallet and account security](wallet-and-security.md): embedded wallet, PIN, 2FA and privacy.
