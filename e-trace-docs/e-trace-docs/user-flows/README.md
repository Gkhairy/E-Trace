# User flows

How each kind of user moves through E-Trace, step by step.

* [Buyer](buyer.md): checkout, escrow, confirm, refund and dispute.
* [Seller](seller.md): store, products, shipping and payouts.
* [Paylater: borrow and fund](paylater.md): borrow against tBNB, or earn by funding the pool.
* [Donate](donate.md): campaigns, disbursements and community wallets.
* [Supervisor](supervisor.md): disputes, held orders, disaster campaigns and banner ads.
